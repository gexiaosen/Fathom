# Fathom 方寸

Fathom（方寸）是一款为室内设计、装修和全屋定制打造的 macOS 户型工具。在 2D 平面图上画墙、开门窗、摆家具、算面积和报价，再切到 3D 查看空间、日照和第一人称漫游。

本地优先：不需要账号，不依赖云同步，方案和偏好保存在本机。

**0.0.2** · macOS 11+ · Apple Silicon / Intel

[下载安装包](https://github.com/gexiaosen/Fathom/releases) · [完整版本记录](CHANGELOG.md)

## 0.0.1 功能

### 画户型

- 绘制承重墙、外墙、隔墙和矮墙，墙体长度、厚度、高度可直接输入精确数值。
- 网格吸附和 Shift 正交约束，拖墙、改墙、测量都能快速对齐。
- 门、窗独立放置，可调整宽度、高度、台高和墙上的位置；门可切换左右铰链与开启方向。
- 承重墙自动保护、不可拆，非承重墙支持拆改。
- 自动识别封闭房间，计算净面积，支持房间重命名。
- 选择、框选、多选、复制、粘贴、删除，以及家具多选对齐。
- 图层可分别开关房间名、家具、网格、尺寸标注、承重墙标示和户型底图。
- 图纸比例支持 1:N，提供适应窗口和全屏查看。

### 摆家具

- 内置 70 件常用家具，分为客厅、卧室、餐厨、卫浴、家电、书房休闲 6 类。
- 家具库支持分类、搜索、收藏和只看收藏。
- 从家具库拖放到平面图，自动避让墙面和已有家具，不能穿墙或重叠。
- 家具支持任意旋转、5° 精细旋转和 90° 快速旋转。
- 宽度、深度、左右位置、上下位置均可精确输入，支持置顶/置底、复制和批量删除。

### 看 3D

- 2D、3D、第一人称漫游三种视图随时切换。
- 3D 支持轨道旋转、滚轮缩放，以及俯视、鸟瞰、斜视三个预设视角。
- 剖切墙模式快速查看室内布局，日照时间轴覆盖 06:00–18:00，支持日间和夜景。
- 房间列表可点击飞行到指定房间。
- 第一人称漫游支持 WASD 移动、鼠标转向、Shift 加速，以及墙体和家具碰撞。
- 门窗在 3D 中按真实洞口显示，家具、材质和灯光随方案同步。

### 面积、材料与报价

- 自动统计每个房间的净面积、总建筑面积和地面计价面积。
- 地面材质可选，按房间计算材料用量。
- 报价默认计入 5% 损耗，输出材料合计、损耗金额、门窗数量和家具件数。

### 文件与出图

- 新建空白方案，或从一室一厅、两室两厅、示例公寓模板开始。
- 打开、另存为、自动保存、最近方案、方案归档。
- 方案信息支持名称、客户、地址和备注。
- 导入户型图作为底图，并自动识别横竖墙线；门窗和弧线手动补齐。
- 导出 PNG、SVG 矢量图、A4 PDF、报价清单 CSV 和 3D 截图，也可直接系统打印。
- 中文 / English 双语界面，完整撤销/重做和常用快捷键。

## 安装

1. Apple Silicon 下载 `Fathom-v0.0.2-arm64.dmg`，Intel Mac 下载 `Fathom-v0.0.2-x86_64.dmg`。
2. 打开 DMG，把 `Fathom.app` 拖入「应用程序」。
3. 当前版本未做 Apple 公证；首次启动如被系统拦截，右键选择「打开」。

## 运行要求

- macOS 11.0 Big Sur 及以上
- Apple Silicon 或 Intel，两个架构分别提供安装包
- 方案数据保存在 `~/Documents/Fathom/`
